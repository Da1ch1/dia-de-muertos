# dia-de-muertos

Landing estática con video especial de Día de Muertos. Despliegue en [Vercel](https://vercel.com).

## Contenido

- `index.html` — página del reproductor
- `video.mp4` — video principal
- `poster.jpg` — poster / Open Graph
- `vercel.json` — cabeceras de caché

## Desarrollo local

Sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
